# 香肠派对 · 大逃杀 🌭

100 人溏心香肠空降大乱斗！纯前端单文件 [index.html](index.html) 实现（原生 Canvas，零依赖，无任何外部资源），**支持手机触屏与电脑键鼠双端游玩**。

## 如何游玩

- **本地玩**：双击打开 `index.html`（手机浏览器同样适用）
- **在线玩**：https://leke2000.github.io/sausage-game/ （若未开启，可在仓库 Settings → Pages 选择 main 分支启用）

## 一局流程

1. **跳伞** — 点击屏幕降落（电脑按空格/鼠标点击），空中可以飘移抢落点，落点靠近城镇装备多
2. **搜刮** — 房区/木箱里捡武器、弹药、护甲、绷带、手雷；白色光柱 = 地面物资，走近按提示拾取
3. **战斗** — 99 个 AI 香肠人各自为战，缩圈把他们赶向你；空投会掉落金色武器
4. **吃鸡** — 活到最后即可「大吉大利，今晚吃鸡！」

## 操作

**电脑**（WASD + 鼠标）

| 按键 | 功能 |
|---|---|
| W A S D | 移动 |
| 鼠标 | 瞄准 |
| 左键 / 空格 | 开火 |
| E | 挥拳 |
| R | 换弹 |
| F | 拾取 |
| Q | 切换武器（双持位） |
| 1 / 2 / 3 | 绷带 / 医疗包 / 肾上腺素 |
| 4 或 G | 丢手雷 |

**手机**（双摇杆）

| 位置 | 功能 |
|---|---|
| 左下屏幕 | 拖动 = 移动摇杆 |
| 右下屏幕 | 拖动 = 瞄准摇杆（推满远处目标） |
| 🔴 开火键 | 按住连发（需右摇杆瞄准中） |
| 挥拳 | 近战应急 |
| 药 / 雷 | 使用医疗品 / 丢手雷 |
| 换弹 | 手动换弹 |
| 点武器盘 | 切换双武器 |

## 玩法内容

- **武器 6+1**：P9手枪 / UZI冲锋枪 / M4A1步枪 / S12霰弹枪 / 98K狙击枪 / 加特林，全部有白/绿/蓝品质（伤害加成），拳头人人自带
- **弹药 4 种**：轻 / 中 / 霰 / 狙，弹药不通用
- **装备**：1~3 级护甲（减伤）、绷带（回满到75）、医疗包（回满）、肾上腺素（加速+回血）、手雷
- **毒圈 6 阶段**：读秒缩圈，越到后面越痛；白虚线圈预告下一个安全区
- **空投**：每隔一段时间掉落金枪 + 3级甲 + 医疗包
- **AI 香肠**：各自搜刮 → 走位互射 → 换弹 → 嗑药 → 残血逃跑，甚至被你打后会反击；开局 12 秒是"落地搜刮期"，大家心照不宣先找枪
- **地图**：河流 / 湖泊 / 树林 / 十字公路 / 5 座城镇群（房区物资密集），全部程序化生成

## 技术要点

- 全部画面（香肠人、武器图标、地图）程序化绘制，无图片资源
- WebAudio 程序化音效（枪声/爆炸/拾取/吃鸡音乐），无音频文件
- 单碰撞分轴移动 + 视线检测（LOS 采样）+ 卡住脱困
- 100 人 AI 状态机（loot / fight / flee / rotate），保证一局 2~3 分钟内自然打完
